QUICKSHOP LADIES BAGS WEBSITE

Files:
- index.html: website structure
- style.css: responsive styling
- script.js: product list, search, categories, cart and WhatsApp ordering
- assets/: six illustrative product image crops

HOW TO CUSTOMIZE
1. Open script.js in any code editor.
2. Near the top, edit WHATSAPP_NUMBER if needed. Use country code + number as digits only, without +, spaces or dashes. Example UAE: 9715XXXXXXXX.
3. Edit the product names, prices and descriptions in the products array in script.js.
4. Replace assets/bag-1.jpg through assets/bag-6.jpg with your own product photos, keeping the same filenames.
5. Open index.html in a browser to preview. For publishing, upload all files and the assets folder to your hosting provider; keep the folder structure unchanged.

IMPORTANT
- The included bag images are illustrative crops from a generated design preview, not verified product photography. Replace them with your actual supplier photos before accepting customer orders.
- WhatsApp orders open a pre-filled message. This is not an online payment gateway, inventory system or delivery integration.
- Prices are sample AED prices; confirm your real prices and delivery terms before publishing.
